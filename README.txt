# Cosmetics Customer Insight Dashboard

## Chạy trên máy
1. Cài Python.
2. Mở CMD/Terminal trong thư mục này.
3. Chạy: pip install -r requirements.txt
4. Chạy: streamlit run app.py
5. Mở địa chỉ Streamlit hiển thị trong Terminal.

## Đưa lên Streamlit Community Cloud
1. Tạo tài khoản GitHub.
2. Tạo repository mới, ví dụ cosmetics-customer-insight-dashboard.
3. Upload 3 file: app.py, requirements.txt, PowerBI_Cosmetics_Customer_Insight_10Topics.xlsx.
4. Vào Streamlit Community Cloud > Create app.
5. Chọn repository, branch và file app.py.
6. Deploy.

Lưu ý: Excel phải nằm cùng thư mục với app.py.
